# 鼠鼠模拟器
# 鼠鼠模拟器分为demo版和正式版
# 原版规则主要有：
## 现金不足会一直掉心态
## 整洁度不够会进入捉老鼠小游戏
# 新版主要做了以下尝试：
## 现金低于2500时会一直掉心态
## 加入玩家头像（鼠鼠表情包），不同选项鼠鼠的表情不同 发量修改为健康值 在鼠鼠头像旁边会显示小红心作为健康值 小蓝心作为心态 这两项增加时会出现动态弹幕+n 特效
## 增加数值触发的特殊事件 eg：头发少了会被推销增发膏
## 原版前中后期数值变化不大 进行更大幅度的数值调整。
## 为了让更多玩家玩到捉老鼠小游戏：加一些扣大量清洁换取心态的事件。
## 加入小游戏：使用鉴定食物新鲜度的方式购买便利店打折食品，发现食物不新鲜的地方越多，购买到的食物越便宜。现金越少越容易触发，游戏成功后会把今日25r饭钱开销替换成便利店打折食物的价格。
## 加入小游戏：同事认可度不够高会出现背锅小游戏。三个人中有一个人说了谎，判断这个人是谁。游戏成功后会增加同事认可度。
## 玩家可以自行选择是否进入小游戏，小游戏成功会加心态。
