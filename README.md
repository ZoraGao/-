# 鼠鼠模拟器

你是一个试用期大厂运营鼠鼠，刚搬进广东城中村出租屋。白天应付工作与同事，晚上照顾自己和房间，在收入、上级评价、健康、心态和整洁之间作出选择。

## 开始游戏

- [Demo 版](demo.html)：从 9 月入职开始，体验 28 天后进入结局。
- [正式版](index.html)：体验 9—12 月试用期，每月 28 天。

两版都是可以直接用浏览器打开的单文件网页，无需安装依赖。表情包、样式和游戏逻辑均已内嵌，也可以通过静态网站托管。微信的文件预览环境可能限制脚本，建议在浏览器中打开网页。

游戏自动保存，也可以随时点击“存档退出”。Demo 与正式版存档独立；存档保存在当前浏览器中，换设备或清理浏览器数据不会保留。

## 前一版改进（正式版仍沿用）

### 头像与状态反馈

- 加入鼠鼠表情包头像，选择后的表情随状态变化切换。
- 将“发量”改为“健康”，头像旁用红心表示健康、蓝心表示心态，同时保留精确数值。
- 除日期外，所有状态在增减时显示对应颜色的动态飘字，包括上级评价、预估工资、现金、健康、心态、同事认可度和整洁。达到上下限时只显示实际变化量。
- 鼠标悬停或键盘聚焦选项时，头像根据该选项的心态增减预览表情；移开后恢复。选项不提前显示具体数值变化。
- 移除游戏底部的规则方框。

### 日常开销与数值调整

- 初始现金 4000 元，每天白天扣除 25 元日常饭钱。
- 现金低于 2500 元时，每天因焦虑扣除 2 点心态；刷新和读档不会重复扣款或扣心态。
- 工资与上级评价挂钩，每月最后一天结束时统一发薪并结算房租、水电；房租为每月 3000 元。
- 加大积极工作路线的收益和健康、心态代价，后半程进一步增加工作消耗。
- 上级评价较高时继续提升的收益降低，健康与心态较高时恢复量降低，扩大不同选择路线的差异。
- 周末不再触发夜晚事件。工作日夜晚保留家务、加班和休闲取舍，选项不显示类型前缀。

### 特殊事件与可选小游戏

- 健康低时可能遇到保健品推销，心态低时可能接到朋友的散步邀请，整洁过低时可能遇到房东检查。
- 增加在出租屋看电影、吃火锅、边吃边开黑等夜晚事件，可以用较大的整洁损失换取心态恢复。
- 提高低整洁度时收拾房间遇到老鼠的概率；玩家可以选择进入抓老鼠小游戏，也可以跳过。
- 新增便利店食品检查：找出包装破损、霉点、过期日期等异常，获得折扣后购买完好的食品。现金越少越容易遇到；发现 1、2、3 处问题时，当天饭钱分别改为 18、12、8 元，退回此前预留的差额。成功增加健康和心态。
- 新增背锅判断：同事认可度不足时可能触发。成功增加同事认可度和心态，失败扣少量心态，跳过不额外扣分。
- 小游戏邀请、食品检查进度及结果支持存档，恢复游戏不会重复领取奖励。

### 背锅逻辑题修订

目前有 5 道职场情境题，涉及活动发布、错误链接、停用优惠券、推送时间和报销金额。

每道题明确说明已知事实和完整的可能范围，并给出小林、小周、小陈各自的一句陈述。题面保证**恰好一人说假话，另外两人说真话**。只靠题面和三个选项即可推出唯一答案，不需要猜同事性格、查询隐藏记录或知道工作常识。

答题后会展示完整推理，说明哪两句话互相矛盾、哪句话因此必须为真，以及为什么只有该人说了谎。悬停这些推理选项不会泄露正确答案。

题库的判断逻辑枚举所有题面允许的可能情况，筛选恰好一句假话的情况。5 道题均验证只有一个可行解；若后续题库意外出现无解或多解，该题会跳过且不扣分。

## 结局与测试

Demo 小游戏统一采用像素风：抓鼠使用像素角色与洞口，接球使用像素球和托盘，KPI 2048 使用方格棋盘，真假话使用三个像素人物头像。小游戏规则和奖励数值保持不变，结果页与存档恢复保留对应样式。成就共13项：3项互斥现实结果、1项提前破产结局、9项可叠加未来成就。

结局同时包含现实结果与多个未来成就。Demo 和正式版使用各自的结局阈值，覆盖转正、无法转正、健康风险、心态告急、同事关系、财务状况和居住状况等方向。

新版已进行脚本语法检查、规则回归检查以及 400 局不同策略的数值模拟。检查涵盖每日扣款去重、小游戏退款、存档恢复、跳过小游戏、正负状态飘字、头像悬停预览和逻辑题唯一解。

数值模拟使用预设选择策略与小游戏成功率，不等同于真实玩家测试。当前尚未完成真实浏览器中的布局、触屏和完整视觉验收。
